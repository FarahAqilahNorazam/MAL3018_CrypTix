PDPA 2010 Data Processing Notice

In accordance with the Personal Data Protection Act 2010 (Act 709) of Malaysia, CrypTix implements strict data minimization:

  • Identity Tokenization: Identity numbers are irreversibly hashed using SHA-256. Raw identification numbers are never retained in plain-text.
  • Password Security: Passwords are protected using salted BCrypt hashing.
  • Session State: Authenticated sessions utilize cryptographically signed JSON Web Tokens (JWT).

Your explicit consent authorizes this cryptographic pipeline to guarantee fair, scalper-free concert access.
